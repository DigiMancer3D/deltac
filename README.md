# 🌀 Delta Calculator

**Find "How Long [un]Till" (HLT) — the projected future date when the same historical progression would occur again.**

A beautiful, single-file, space-themed calculator that lets you explore computational, historical, religious, societal, and quantum progression deltas using emoji toggles.

> Only the four core deltas start **ON** by default. Everything else is OFF until you toggle it. All corrective deltas update **live** in real time.

## ✨ Features

- **Core progression deltas**:
  - 👤 → ⚙️ Human Computers → 1st Machine Computers
  - ⚙️ → 🤖 1st Machine Computers → 1st AI that writes its own code
  - 🧠 → 🤖 1st LLM → 1st AI
  - 🔄 Corrective Baseline (original Apollo-era anchor)

- **Huge scrollable library** of additional deltas:
  - USA, Global, Britain, Viking history
  - Religious timelines
  - Society & fame spans
  - Human & tech lifespan deltas
  - **4 brand-new Quantum Computing deltas**

- **Live Dynamic Corrective Deltas**:
  - Religious Corrective
  - Society Corrective
  - **Quantum Corrective** (new — based on all computer-based deltas)
  - Ultimate Corrective (tames the total sum)

- If any corrective group has **no active base deltas**, it automatically uses a random value between **-1 and -9 years**.

- **Fancy space-themed scrollbar** (green glow, matches the dark cosmic aesthetic)

- Real-time maths breakdown in the footer

- Default base-change formula when nothing is selected:

  +(((3.14^random(1-3))/MEDIAN_YEARS)+1) years

- Supports both formatted dates (`yyyy/mm/dd hh:mm:ss`) and raw Unix epoch milliseconds

- Fully self-contained — **one single HTML file**, zero dependencies

## 🚀 How to Use

1. Download or copy the entire HTML file.
2. Save it as `deltac.html`.
3. Open the file in any modern browser (Chrome, Firefox, Edge, Safari).
4. Toggle deltas on/off.
5. Enter a date/epoch or click **NOW**.
6. Hit **CALCULATE DELTA OUTPUT** (or press Enter).

The projected "Delta Date" instantly updates with live maths shown below.

## 🧬 What is a Delta?

Each emoji pair represents a real historical time span:

- `👤 → ⚙️` = ~10.8 years (human computers → machine computers)
- `📈 → ⚡` = Moore’s Law period
- Quantum, religious, society, and lifespan deltas all contribute their own measured intervals.

Corrective deltas automatically subtract averaged time to keep projections grounded.
